# PowerShell Menu

This project is a simple PowerShell script that provides a command-line menu interface.

## Usage

To use this menu, run the `main.ps1` script from a PowerShell terminal:

```powershell
./main.ps1
```

## Features

The menu provides the following options:

*   **Show System Information:** Displays basic information about the computer.
*   **List Directory Contents:** Lists files and folders in a user-specified directory.
*   **Run a Custom Script:** Allows running an arbitrary PowerShell script from a specified path.
*   **Start Windows Defender Scan:** Provides options for Quick, Full, or Custom anti-malware scans using Windows Defender.
*   **Update Windows Defender Signatures:** Updates Windows Defender's anti-malware definitions.
